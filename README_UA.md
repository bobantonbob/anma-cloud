# ANMA Cloud

Інтеграція Home Assistant для вебдашборда ANMA Cloud. Вона надає вибрані показники сонця, мережі, батареї та навантаження через API лише для читання.

## Дашборд і реєстрація

[Відкрити ANMA Cloud](https://cloud.anma-electric.com.ua/app/). Сервіс публічно доступний: [зареєструйтеся](https://cloud.anma-electric.com.ua/register/) через email і пароль, підтвердьте email та [увійдіть](https://cloud.anma-electric.com.ua/login/). Для створення облікового запису не потрібно звертатися до власника репозиторію. Для підключення HA потрібна мережева доступність через Tailscale.

## Встановлення через HACS

1. Встановіть HACS у Home Assistant.
2. [Додайте ANMA Cloud](https://my.home-assistant.io/redirect/hacs_repository/?owner=bobantonbob&repository=anma-cloud&category=integration). До прийняття в основний каталог додайте `https://github.com/bobantonbob/anma-cloud` як власний репозиторій категорії **Integration**.
3. Завантажте ANMA Cloud у HACS і перезапустіть Home Assistant.
4. Відкрийте Налаштування → Пристрої та служби → Додати інтеграцію → ANMA Cloud.
5. У налаштуваннях інтеграції оберіть джерела показників і збережіть прив’язки.

HACS надалі керує оновленнями. Оновлення зберігає наявні прив’язки; видаляти інтеграцію не потрібно.

Для ручного встановлення завантажте вихідний ZIP із [Releases](https://github.com/bobantonbob/anma-cloud/releases), скопіюйте `custom_components/anma_cloud` у `/config/custom_components/anma_cloud` та перезапустіть HA.

## Підключення

У налаштуваннях інтеграції створіть одноразовий код на 15 хвилин. У вебдашборді оберіть додавання будинку, введіть назву, Tailscale IPv4 адресу HA та код. Сервер дашборда повинен мати дозволений доступ до HA через Tailscale. Реєстрація та код самі не встановлюють Tailscale і не надають мережевого доступу. Не відкривайте цей API у публічний інтернет.

Для кількох інверторів додайте окремий запис інтеграції для кожного, з окремими прив’язками й кодами. У дашборді додайте їх окремо з тією ж IP-адресою та відповідними кодами. Ця можливість підтримується з v0.4.4; сервер також має підтримувати кілька installation ID за однією адресою.

## Які дані отримує сервіс

Після підключення сервер опитує API інтеграції та отримує нормалізовані вибрані показники сонця, мережі, батареї, навантаження, стану інвертора, енергії та прогнозів, їхні одиниці, ідентифікатор інсталяції й доступну історію вибраних показників із Recorder. Сервіс також отримує email облікового запису, введені назву будинку та Tailscale адресу HA, а після pairing — обмежений ключ читання.

Повний токен HA не потрібний. Доступу до невибраних сутностей і команд керування інвертором інтеграція не надає. Без підключеного вебдашборда локальні стандартизовані сенсори самі не створюють вебвізуалізацію.

## Підтримка та перевірки

[Повідомити про проблему](https://github.com/bobantonbob/anma-cloud/issues). Не публікуйте ключі, коди підключення, приватні адреси або дампи HA.

Тести: `python tests/test_mapping.py` і `python tests/test_connector.py`. Вони підміняють API Home Assistant тестовими об’єктами; перевірка в реальному HA також потрібна.
